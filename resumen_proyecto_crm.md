# Resumen Ejecutivo: Angel Curbelo Sales CRM

## 1. Identidad y Branding
*   **Nombre Comercial:** Angel Curbelo Sales.
*   **Concepto:** Gestión Premium de Soluciones para el Hogar (Solar, Bienestar, Seguridad).
*   **AEstética:** Dark Mode con acentos en Oro (`#d4af37`), tipografías modernas (Outfit e Inter) y efectos de glassmorphism.

## 2. Arquitectura Técnica
*   **Frontend:** Single Page Applications (SPA) y landing pages optimizadas con Vite.
*   **Backend:** Ecosistema Firebase (Firestore para base de datos, Hosting para despliegue, Functions para lógica de servidor).
*   **Integraciones:** Make.com y Twilio para notificaciones de WhatsApp (pendientes de datos finales del cliente).

## 3. Sistema de Captación (Landing Pages)
Se han desarrollado 4 embudos independientes integrados en una sola base de datos:
1.  **SolarFlow Pro:** Captación de leads para energía solar.
2.  **Bienestar Total (HH Distributors):** Sistema integral de purificación de agua y aire.
3.  **Rainbow PR:** Demostraciones de salud respiratoria y limpieza profunda.
4.  **Zendure PR (Fase de Expansión):** Respaldo energético inteligente (Baterías Plug & Play).

## 4. Panel Administrativo (CRM Premium)
*   **Gestión Segmentada:** Capacidad de filtrar prospectos por servicio o ver la base global.
*   **Pipeline de Ventas:** Flujo de estados (Nuevo, Contactado, Cita, Venta) con archivo automático de leads no cualificados (Renta, Apartamento, Crédito).
*   **Deep Linking:** Navegación por hashes (`#`) que permite compartir o guardar vistas específicas (ej. `#creativos-bienestar`).

## 5. Herramientas de Marketing
*   **Generador de Campañas:** Motor de ideas que genera "Hooks" y cuerpos de anuncios específicos para Facebook, Instagram y TikTok por cada segmento.
*   **Función "One-Click":** Descarga del recurso visual y copia del texto al portapapeles en un solo paso para agilizar el lanzamiento de campañas.
*   **Archivo de Creativos:** Sistema para guardar y reutilizar anuncios exitosos.

## 6. Inteligencia de Datos (Estadísticas)
*   **Dashboard en Tiempo Real:** Visualización de métricas clave mediante Chart.js.
*   **KPIs Dinámicos:** Seguimiento de tasa de conversión, volumen total y segmento con mayor crecimiento.
*   **Filtros de Análisis:** Capacidad de analizar el rendimiento global o profundizar en las métricas de un solo producto.

## 7. Estado Actual
El proyecto se encuentra en fase de **Base Funcional Completa**. Toda la infraestructura técnica, la lógica de negocio y el diseño premium están desplegados y validados, a la espera de la información final del cliente para la carga de datos y ajustes menores de personalización.
